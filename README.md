# Progressive Tax Calculator

## What It Does

This app calculates tax using three progressive tax brackets. It displays the income and tax owed, and shows an error for invalid or negative income.

## Built With

- Python
- Flask
- HTML
- CSS

## How to Run It

1. Open a terminal in the project folder.
2. Create a virtual environment: `py -m venv venv`
3. Activate it: `.\venv\Scripts\Activate.ps1`
4. Install Flask: `python -m pip install flask`
5. Run the app: `python app.py`
6. Open `http://127.0.0.1:5000` in a browser.

## Screenshot Description

The home page shows an annual income field and a Calculate button. The results page shows the income, tax owed, and a Calculate Another link.
